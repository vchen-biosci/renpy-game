Programming language: Ren'Py.
Watched these tutorials to start out, then followed the Ren'Py basic tutorial and dug through documentation for the rest of the coding:
> [https://www.youtube.com/watch?v=DnhCVv-jpqo]
> [https://www.youtube.com/watch?v=_zq3V28qp2w]

I'm learning a lot of things from this project. Every change I've made to the Ren'Py code is something new that I didn't know how to do before starting. For instance, I learnt how to customise GUI, customise dialogue text, offer choices, and loop through music. I've learnt new things even beyond coding too. I found that using Obsidian is a very good way to keep track of different story nodes, and experimented with different naming conventions for story branches!
